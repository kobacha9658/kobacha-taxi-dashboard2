こばちゃ専用タクシーダッシュボード：国内線運航状況版

1. index.html を GitHub Pages の公開ルートにある index.html と置き換えてください。
2. コミットして公開してください。
3. 八重洲・羽田の4カメラと60秒更新は維持しています。
4. 鉄道用 rail-status.json の取得処理はありません。
5. 羽田空港公式の国内線遅延・欠航ページを iframe で表示します。公式側が埋め込みを制限する場合は表示されないため、ページ内の公式リンクから開いてください。
6. 「遅延・欠航はありません」という表示は公式ページの情報に依存します。通信エラーや埋め込み失敗時は「ありません」と誤表示しないよう、公式ページを直接確認する案内を表示しています。
