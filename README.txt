こばちゃ専用 タクシー情報ダッシュボード（再構築版）

内容：
- index.html：ダッシュボード本体（八重洲2画面・羽田2画面・鉄道情報リンク）

今回の版では、存在しない data/rail-status.json を読みに行く処理を外しました。
そのため、このJSONファイルがないことによる HTTP 404 表示は出ません。

鉄道情報について：
Yahoo!路線情報の関東・新幹線ページをボタンから開いて最新状況を確認する方式です。
この版は鉄道の遅延情報を自動取得して一覧表示するものではありません。取得できていないのに
「平常運転」と誤表示するのを避けるためです。

設置手順（GitHub Pages）：
1. ZIPを解凍する
2. 中の index.html を開かずに、そのファイルをGitHubリポジトリのトップ階層へアップロードする
3. 同名の index.html がある場合は置き換える（変更前のファイルは念のため保存）
4. Commit changes で保存する
5. 1〜3分待ってサイトを再読み込みする

注意：このZIPをこちらから直接GitHubへ反映することはできません。
